# 📊 End-to-End Data Analytics Project: Superstore Sales 

هذا المشروع عبارة عن تحليل متكامل لبيانات مبيعات متجر ضخم (Superstore) يمر بجميع مراحل تحليل البيانات من الاستخراج والتنظيف إلى العرض النهائي.

## 🛠️ التقنيات والأدوات المستخدمة:
1. **SQL (MySQL):** لإنشاء قاعدة البيانات، استيراد البيانات الخام، وإجراء استعلامات الفحص الأولية.
2. **Python (Pandas):** لتنظيف البيانات، معالجة القيم المفقودة، وتصحيح أنواع البيانات (قريباً).
3. **Power BI:** لإنشاء لوحة تحكم تفاعلية (Dashboard) واستخراج الرؤى (قريباً).

## 📂 هيكل المشروع الحقيقي:
* `train.csv`: البيانات الخام (Raw Data) وتحتوي على 9,800 صف.
* `1_database_setup.sql`: كود SQL الأساسي لإنشاء القاعدة وتجهيز الجدول.
